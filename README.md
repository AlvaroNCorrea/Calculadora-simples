# 🧮 Calculadora Interativa em Python

![Python](https://img.shields.io/badge/python-3.6%2B-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Uma calculadora simples, robusta e interativa executada diretamente no terminal. Desenvolvida em Python, este projeto foi criado para consolidar conceitos de funções, estruturas de repetição (`while`), tomadas de decisão (`if/elif/else`) e tratamento de exceções básicas (como divisão por zero).

## 🚀 Funcionalidades

O programa oferece as quatro operações matemáticas básicas em um menu interativo contínuo:
- **Soma (+)**
- **Subtração (-)**
- **Multiplicação (x)**
- **Divisão (/)** com validação para impedir divisão por zero.

## 🛠️ Tecnologias Utilizadas

- **Python 3** (estruturas de controle, loop infinito de interação e modularização de funções).
